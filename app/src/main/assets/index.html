Find music privately
  1. Open the official Tor Browser yourself and visit commons.wikimedia.org. Look for a gentle recording, not a MIDI file.
  2. On that file’s page, check the recording’s license and any credit requirements, then download the audio. You do not need to sign in.
  3. Return here, tap Import music files, choose the download, and preview it before setting an alarm.

Petal Wake does not contact the music site when importing a local file. Tor Browser protects only the browsing done inside it.

Moving to a new phone

  1. Save the settings file above and move it to your new phone using a storage location you trust.
  2. Install Petal Wake on the new phone, then restore that settings file.
  3. In Proton Calendar, create a fresh Limited view link for your work-only calendar. Connect it on the new phone. Recreate any personal alarms.
  4. Allow Android alarm permissions, enable Work alarms, and confirm the next wake-up time with a test alarm.
  5. After the new phone is working, delete the old sharing link in Proton Calendar.

The settings file never contains your calendar link. You can also reconnect with a Full view link if you use title filtering.

Music & credits

The music uses real performances from the Musopen DVD compilation, marked Public Domain Mark 1.0. The Gentle music section adds eight softer orchestral edits and eight new solo-piano movements, selected for steadier passages. All 54 music and nature recordings now have balanced levels, reduced swells and two-second crossfaded loop joins. The six nature sounds use CC0 recordings. Every selection includes its source, recordist or performer, and license below. Full edit details are bundled in credits.txt.

The 12 standard alarm tones were created for Petal Wake and released under CC0 1.0.

Calendar parsing: biweekly 0.6.8 (BSD 2-Clause), vinnie 2.0.2 (BSD 2-Clause), Google recurrence code (Apache 2.0). Full notices are included with the source.
